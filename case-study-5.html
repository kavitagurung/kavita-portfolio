CASE STUDY

ClauseGraph RAG

A local document intelligence assistant for source-grounded questions over contracts, policies, and internal knowledge bases.

Problem

Finding a reliable answer across long documents is slow when users cannot easily trace an answer back to its source.

Solution

Built a local RAG application that retrieves relevant document passages and generates answers with the matching source chunks visible in the interface.

Technical approach

Implemented a Python Flask backend with Ollama embeddings and chat models, plus a browser-based interface for document and query workflows.

Document workflow

Supports PDF, TXT, and Markdown uploads, semantic indexing, queries across all files or a chosen document, and removal of files with their indexed vectors.

Product decisions

Kept the system local-first and made retrieved evidence inspectable, so users can assess the basis for an answer rather than treating it as a black box.

Explore the project

The repository includes the Flask API, browser UI, local index structure, and regression tests for core document handling flows.
